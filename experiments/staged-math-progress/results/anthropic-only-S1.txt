# S1: Definitions and assumptions

## Universe and Types

Let `Transition` be an arbitrary non-empty type (a set of candidate transitions). All predicates below are total functions from `Transition` to `Prop`.

## Primitive Predicates (Opaque)

| Symbol | Type | Meaning |
|--------|------|---------|
| `GBP` | `Transition → Prop` | Opaque predicate 1; no internal structure assumed |
| `BD` | `Transition → Prop` | Opaque predicate 2; no internal structure assumed |
| `OC` | `Transition → Prop` | Opaque predicate 3; no internal structure assumed |

No logical relationship among `GBP`, `BD`, `OC` is assumed. In particular, none is assumed to imply, exclude, or overlap with any other.

## Defined Predicate

**Definition (ALLOW).** For all `t : Transition`:

```
ALLOW t  :⟺  GBP t ∧ BD t ∧ OC t
```

This definition is the *sole* content of `ALLOW`. It is stipulated, not derived.

## Assumptions in Force

1. **A1 (Totality).** Every predicate is defined on all elements of `Transition`.
2. **A2 (Classical logic).** Standard propositional reasoning (LEM, double-negation elimination) is available. The Lean 4 candidate will use `Classical` where needed.
3. **A3 (No further axioms).** No axioms about `GBP`, `BD`, `OC`, or `ALLOW` beyond Definition ALLOW and A1–A2 are admitted.

## Necessary-and-Sufficient Characterization (Statement)

**Theorem (N&S-ALLOW).** For every `t : Transition`:

```
ALLOW t  ↔  GBP t ∧ BD t ∧ OC t
```

*Necessity* (`→`): If `ALLOW t` holds, then `GBP t`, `BD t`, and `OC t` each hold individually.

*Sufficiency* (`←`): If `GBP t`, `BD t`, and `OC t` all hold, then `ALLOW t` holds.

**Corollary (failure modes, by contrapositive).** `¬ ALLOW t` holds if and only if at least one of `¬ GBP t`, `¬ BD t`, `¬ OC t` holds:

```
¬ ALLOW t  ↔  ¬ GBP t ∨ ¬ BD t ∨ ¬ OC t
```

## Claim Boundary (Reiterated for This Stage)

All statements above are logical consequences of Definition ALLOW under A1–A3. No claim is made about any deployed system. The Lean 4 candidate (S2) will formalize exactly this theorem and corollary, nothing more.
