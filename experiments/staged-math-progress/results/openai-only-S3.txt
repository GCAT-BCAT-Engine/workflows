S3: Proof strategy and lemma decomposition.

- **Forward / necessity:** Assume `hAllow : ALLOW t`. Apply `(contract t).mp` to derive `GBP t ∧ BD t ∧ OC t`.
- **Reverse / sufficiency:** Assume `hChecks : GBP t ∧ BD t ∧ OC t`. Apply `(contract t).mpr` to derive `ALLOW t`.
- Combine both implications with `Iff.intro`.

```lean
theorem allow_admissible
    {Transition : Type}
    (GBP BD OC ALLOW : Transition → Prop)
    (contract : ∀ t, ALLOW t ↔ (GBP t ∧ BD t ∧ OC t))
    (t : Transition) :
    ALLOW t ↔ (GBP t ∧ BD t ∧ OC t) := by
  apply Iff.intro
  · intro hAllow
    exact (contract t).mp hAllow
  · intro hChecks
    exact (contract t).mpr hChecks
```

This proves necessity and sufficiency only under the stipulated abstract evaluator contract; it does not specify a deployed engine or establish implementation validity.
