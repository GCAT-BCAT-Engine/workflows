## 1. Task Identity

**Experiment:** SV-COST-STAGED-001
**Problem:** Characterize ALLOW admissibility for an *abstract* GCAT/BCAT evaluator.
**Scope constraint:** No deployed engine is specified; no implementation conformance is claimed.

---

## 2. Stipulated Abstract Evaluator (verbatim restatement)

Let `GBP`, `BD`, `OC` be uninterpreted predicates on a candidate transition `t`. The evaluator returns `ALLOW` exactly when all three predicates hold:

```
ALLOW(t) ↔ GBP(t) ∧ BD(t) ∧ OC(t)
```

This is a **stipulated definition**, not a derived result. It is admitted as the sole semantic axiom of the abstract evaluator.

## 4. Boundary Demarcations

- **"Deployed":** No deployed system is referenced. The evaluator is purely abstract.
