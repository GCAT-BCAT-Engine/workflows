## 1. Task Parsing

**Problem statement (restated verbatim for identity preservation):**
Characterize ALLOW admissibility for an abstract GCAT/BCAT evaluator. Let GBP, BD, and OC be predicates on a candidate transition. The evaluator returns ALLOW exactly when GBP and BD and OC all hold. Establish the necessary-and-sufficient characterization, state the claim boundary, and prepare a Lean 4 candidate for the logical core.

**Identified components:**

| Symbol | Role |
|---|---|
| `T` | Type of candidate transitions (abstract, unspecified) |
| `GBP : T → Prop` | Predicate: "good base policy" condition |
| `BD : T → Prop` | Predicate: "boundary" condition |
| `OC : T → Prop` | Predicate: "output condition" |
| `ALLOW : T → Prop` | Target admissibility predicate |

**Governing logical relationship (stipulated by problem):**
> The evaluator returns ALLOW exactly when GBP and BD and OC all hold.

This is a definitional biconditional:

```
∀ t : T, ALLOW t ↔ (GBP t ∧ BD t ∧ OC t)
```

---

## 2. Claim Boundary

**What is being claimed (and what is not):**

| Category | Status |
|---|---|
| The biconditional `ALLOW t ↔ GBP t ∧ BD t ∧ OC t` is the necessary-and-sufficient characterization, as stipulated. | **Stipulation** — accepted as the problem's defining condition; not an independently verified empirical fact. |
| The Lean 4 candidate to be produced in a later stage will correctly encode this biconditional as a proposition in Lean 4's type theory. | **Claim to be established in S2 (Lean 4 stage)** — not yet asserted. |
| Any deployed GCAT/BCAT system conforms to this characterization. | **Explicitly disclaimed** — no implementation validity is claimed. |
| The predicates GBP, BD, OC are logically independent of one another. | **Unresolved** — not assumed, not denied; left abstract. |
| The type `T` is non-empty or has any particular structure. | **Unresolved** — left fully abstract. |

**Necessity direction:** If `ALLOW t` holds, then `GBP t ∧ BD t ∧ OC t` holds.
**Sufficiency direction:** If `GBP t ∧ BD t ∧ OC t` holds, then `ALLOW t` holds.

Both directions are entailed by the stipulated biconditional. They require no independent proof beyond the definition; any Lean 4 proof will discharge them by `Iff.intro` applied to the definition.
