### 2. Principal Theorem

**THEOREM-1 (ALLOW Admissibility — Necessary and Sufficient Characterization).**

> Let `T` be an arbitrary non-empty type.
> Let `GBP`, `BD`, `OC` : `T → Prop` be uninterpreted total predicates (DEF-2).
> Define `ALLOW(t) := GBP(t) ∧ BD(t) ∧ OC(t)` (DEF-3).
>
> Then for all `t : T`:
>
> ```
> ALLOW(t)  ↔  GBP(t) ∧ BD(t) ∧ OC(t)
> ```
>
> That is:
>
> - **(Necessity / Forward direction):** `ALLOW(t) → GBP(t) ∧ BD(t) ∧ OC(t)`
> - **(Sufficiency / Backward direction):** `GBP(t) ∧ BD(t) ∧ OC(t) → ALLOW(t)`

### 3. Decomposition of Proof Obligations

**Proof obligation PO-1 (Forward / Necessity).**

```
Assume: ALLOW(t)
Goal:   GBP(t) ∧ BD(t) ∧ OC(t)

By DEF-3, ALLOW(t) is definitionally equal to GBP(t) ∧ BD(t) ∧ OC(t).
The assumption unfolds directly to the goal.
Proof: by definition.
```

**Proof obligation PO-2 (Backward / Sufficiency).**

```
Assume: GBP(t) ∧ BD(t) ∧ OC(t)
Goal:   ALLOW(t)

By DEF-3, ALLOW(t) is definitionally equal to GBP(t) ∧ BD(t) ∧ OC(t).
The goal unfolds directly to the assumption.
Proof: by definition.
```

**Summary.** Both directions reduce to definitional unfolding. No lemmas
