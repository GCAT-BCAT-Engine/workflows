### Stipulations reused
Let:
- `Transition` and `Outcome` be arbitrary types;
- `ALLOW : Outcome`;
- `eval : Transition → Outcome`;
- `GBP BD OC : Transition → Prop`;
- `Allowed t := eval t = ALLOW`;
- `Conditions t := GBP t ∧ (BD t ∧ OC t)`.

Assume:
\[
allow\_spec:\forall t,\quad
eval(t)=ALLOW\leftrightarrow GBP(t)\land(BD(t)\land OC(t)).
\]

### Proof strategy
Fix an arbitrary transition `t`.

1. Instantiate `allow_spec` at `t`.
2. Use its forward implication to prove necessity:
   \[
   eval(t)=ALLOW\to GBP(t)\land(BD(t)\land OC(t)).
   \]
3. Use its reverse implication to prove sufficiency:
   \[
   GBP(t)\land(BD(t)\land OC(t))\to eval(t)=ALLOW.
   \]
4. Introduce the biconditional and combine those two implications.
5. Generalize over `t`.

Because the target is exactly the instantiated specification, a shorter proof is also available: introduce `t` and apply `allow_spec t` directly.

### Lemma decomposition

#### Necessity lemma
```lean
theorem allow_implies_conditions
    {Transition Outcome : Type}
    (ALLOW : Outcome)
    (eval : Transition → Outcome)
    (GBP BD OC : Transition → Prop)
    (allow_spec :
      ∀ t, eval t = ALLOW ↔ GBP t ∧ (BD t ∧ OC t)) :
    ∀ t, eval t = ALLOW → GBP t ∧ (BD t ∧ OC t) :=
  by
    intro t hAllow
    exact (allow_spec t).mp hAllow
```

This uses the forward direction of the stipulated biconditional.

#### Sufficiency lemma
```lean
theorem conditions_imply_allow
    {Transition Outcome : Type}
    (ALLOW : Outcome)
    (eval : Transition → Outcome)
    (GBP BD OC : Transition → Prop)
    (allow_spec :
      ∀ t, eval t = ALLOW ↔ GBP t ∧ (BD t ∧ OC t)) :
    ∀ t, GBP t ∧ (BD t ∧ OC t) → eval t = ALLOW :=
  by
    intro t hConditions
    exact (allow_spec t).mpr hConditions
```

This uses the reverse direction of the stipulated biconditional.
